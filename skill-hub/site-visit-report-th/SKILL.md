# รายงานสำรวจหน้างาน (Site Visit Report)

เรียบเรียงข้อมูลดิบจากการสำรวจหน้างานเป็นรายงานภาษาไทยที่ส่งลูกค้าหรือหัวหน้าได้ทันที

## ขั้นตอน

1. อ่านข้อมูลทั้งหมดที่ได้รับ (โน้ต รูป ตาราง ไฟล์แนบ) แยก **ข้อเท็จจริงที่เห็นจริง** ออกจาก **ข้อสันนิษฐาน**
2. ถ้าขาดข้อมูลสำคัญ (ชื่อลูกค้า สถานที่ วันที่ ผู้สำรวจ) ให้เว้นเป็น `[ระบุ]` อย่าแต่งขึ้นเอง
3. เขียนตามโครงสร้างด้านล่าง ใช้ภาษาทางการ กระชับ หน่วยวัดเป็น SI
4. ปิดท้ายด้วย "สิ่งที่ต้องยืนยันกับลูกค้า" เสมอ

## โครงสร้างรายงาน

```
1. ข้อมูลทั่วไป        ลูกค้า / สถานที่ / วันที่สำรวจ / ผู้สำรวจ / ผู้ประสานงานฝั่งลูกค้า
2. วัตถุประสงค์         งานที่ลูกค้าต้องการ 1–3 บรรทัด
3. สภาพหน้างาน         พื้นที่ ตู้ไฟ แหล่งจ่ายไฟ (V/A) สายสัญญาณ เครือข่าย (LAN/Wi-Fi/4G) สภาพแวดล้อม (ฝุ่น ความชื้น อุณหภูมิ)
4. อุปกรณ์ที่มีอยู่      ตาราง: ชื่อ | ยี่ห้อ/รุ่น | โปรโตคอล | ตำแหน่ง | หมายเหตุ
5. ข้อเสนอทางเทคนิค    แนวทางเชื่อมต่อ อุปกรณ์ที่ต้องเพิ่ม แผนผังอย่างง่าย
6. ความเสี่ยงและข้อจำกัด
7. สิ่งที่ต้องยืนยันกับลูกค้า (checklist)
8. ภาพประกอบ          อ้างอิงชื่อไฟล์รูปพร้อมคำบรรยาย
```

## กฎ

- ตัวเลขทุกตัวต้องมาจากข้อมูลที่ได้รับ ถ้าประมาณเองให้เขียนว่า "(ประมาณ)"
- ชื่ออุปกรณ์ รุ่น และ IP ให้คงตามต้นฉบับ ไม่แปล
- ไม่ใส่รหัสผ่านหรือข้อมูลลับของลูกค้าในรายงาน แม้จะอยู่ในโน้ต
- ถ้าผู้ใช้ขอเป็นไฟล์ ให้ส่งเป็น Markdown ที่นำไปวางใน Word หรือในระบบ Site Visit ได้
